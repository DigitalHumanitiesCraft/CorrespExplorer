PromptotypingPromptotyping ist eine iterative Context-Engineering-Arbeitstechnik, um datengetrieben und gemeinsam mit Frontier-LLMs Forschungsartefakte wie Interfaces, Tools oder Workflows zu entwickeln. Im Promptotyping Vault ist das Wissen zum CorrespExplorer destilliert. Demo: Dieses Projekt befindet sich in aktiver Entwicklung. Ideen und Bugs koennen gerne als Issues im GitHub-Repo dokumentiert werden.
