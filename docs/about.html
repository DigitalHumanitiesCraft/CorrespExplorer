Über CorrespExplorer

Was ist CorrespExplorer?

CorrespExplorer ist ein webbasiertes Werkzeug zur Visualisierung und Exploration von Korrespondenz-Metadaten. Es wurde entwickelt, um Briefeditionen und Korrespondenzprojekte interaktiv erfahrbar zu machen.

Die Anwendung verarbeitet Daten im CMIF-Format (Correspondence Metadata Interchange Format) und in TEI-Briefsätzen. Der Explorer ordnet seine Darstellungen nach den Gegenständen Start, Briefe, Personen, Orte, Zeit und Themen, darunter Karte, Raum-Zeit-Ansicht, Korrespondenzkreis und Vergleich.

Das CMIF-Format

CMIF (Correspondence Metadata Interchange Format) ist ein auf TEI-XML basierendes Format zum Austausch von Korrespondenz-Metadaten. Es wurde von der TEI Correspondence SIG entwickelt und ermöglicht die Vernetzung verschiedener Briefeditionen.

CMIF enthält typischerweise

  • Absender und Empfänger (mit Normdaten-Verknüpfung)
  • Datum und Zeitraum
  • Absendeort (mit GeoNames-Kennung)
  • Sprache des Briefs
  • Themen und Schlagworte
  • Verweise auf die Quelledition

Koordinaten enthält CMIF nicht. CorrespExplorer ergänzt sie beim Laden aus einer mitgelieferten Tabelle, die GeoNames-Kennungen über Wikidata Koordinaten zuordnet, und auf Wunsch aus Wikidata.

CMIF-Spezifikation auf correspSearch

correspSearch

correspSearch ist ein Webservice der Berlin-Brandenburgischen Akademie der Wissenschaften, der Briefmetadaten aus verschiedenen Editionen aggregiert und durchsuchbar macht.

CorrespExplorer kann CMIF-Daten direkt von correspSearch laden, wenn unter „Eigene Daten“ die Adresse einer Abfrage eingegeben wird. Die API ermöglicht Abfragen nach Korrespondenten, Zeiträumen und anderen Kriterien.

Darstellungen

Die Kopfzeile des Explorers nennt sechs Gegenstände. Ein Gegenstand mit mehreren Darstellungen listet sie unter seinem Reiter. Ein Gegenstand, für den der Bestand nichts enthält, erscheint nicht.

Start

Kleine Darstellungen von Zeit, Sprachen, Personen, Orten und Themen des Bestands, jede wählt aus und filtert

Briefe

Briefliste mit Suche, Sortierung und einem Jahresprofil zum Springen

Personen

Liste, Netzwerk mit dem Korrespondenzkreis um eine Person, Erwähnungen als Sankey-Fluss, Vergleichen

Orte

Karte der Absendeorte, Raum-Zeit mit den Jahren als Höhe über der Karte, Liste, Vergleichen

Zeit

Briefe je Jahr nach Sprache, der gewählte Zeitraum nach Monaten oder als einzelne Briefe, Vergleich zweier Zeiträume

Themen

Themen über die Jahre als Raster und nach ihren Anteilen

Umgang mit Unsicherheit

Historische Korrespondenzdaten enthalten oft Unsicherheiten und Lücken. CorrespExplorer erkennt diese automatisch und zeigt sie an.

Visuelle Symbole für Datumsangaben

Unvollständiges Datum Nur Jahr oder Jahr-Monat bekannt (z.B. "Jun 1900")
Zeitraum Brief wurde zwischen zwei Daten verfasst (notBefore/notAfter)
Unsichere Datierung Die Quelle markiert das Datum als unsicher (cert="low")
Datum unbekannt Kein Datum in den Metadaten vorhanden

Unscharfe Daten in der Ansicht Zeit

Im Balken eines Jahrs zeigt eine diagonale Schraffur den Anteil der Briefe mit unscharfem oder erschlossenem Datum. Im gewählten Zeitraum steht ein solcher Brief als offener Ring mit seiner Spanne. Die Legende nennt die Zahlen, wenn der Zeiger auf ihrem Eintrag ruht.

Weitere erkannte Unsicherheiten

  • Orte ohne Koordinaten, etwa Regionen wie "Steiermark", stehen in der Ortsliste, aber nicht auf Karte und Raum-Zeit.
  • Absender oder Empfänger, die die Quelle als [NN] oder "Unbekannt" verzeichnet, gelten als unbekannte Personen.
  • Personen ohne VIAF- oder GND-Verknüpfung tragen in der Personenliste den Vermerk „ohne Normdatensatz“.

Das Zeichen „Bestand“ in der schmalen Leiste am Rand des Explorers zeigt, welcher Anteil der Briefe exakt datiert ist, identifizierte Personen nennt und lokalisierte Orte hat. Die Gruppe „Datenlage“ darunter filtert nach diesen drei Merkmalen.

Unsicherheit steht dort, wo sie auftritt, und das Werkzeug gibt keine Präzision vor, die die Quelle nicht hat.

Technologie

CorrespExplorer ist eine clientseitige Webanwendung ohne eigenes Backend.

  • JavaScript, HTML und CSS ohne Build-Schritt, die Bibliotheken liegen im Repository
  • Karte mit MapLibre GL JS und der Grundkarte von OpenFreeMap
  • CMIF und TEI werden im Browser gelesen
  • Export als CSV und JSON

Der Quellcode ist auf GitHub verfügbar und kann frei verwendet werden.

Datenschutz

CorrespExplorer verarbeitet alle Daten lokal im Browser. Hochgeladene Dateien werden nicht auf einem Server gespeichert.

Von sich aus fragt das Werkzeug nur einen externen Dienst an. Die Grundkarte lädt Kartenkacheln von OpenFreeMap, sobald eine Karte angezeigt wird. Dabei erfährt OpenFreeMap wie jeder Webserver die IP-Adresse des Browsers und den gezeigten Kartenausschnitt.

Alle weiteren Anfragen lösen Sie selbst aus.

  • Eine eingegebene Adresse lädt die Daten direkt von dieser Quelle, eine Abfrage an correspSearch von der API der Berlin-Brandenburgischen Akademie der Wissenschaften.
  • Die Anreicherung über Wikidata fragt Koordinaten, Lebensdaten, Berufe und Porträts erst nach Bestätigung ab, die Porträts kommen von Wikimedia Commons.
  • Links zu Editionen, Normdaten und correspSearch öffnen die Seite des jeweiligen Anbieters.

Entwicklung und Methodik

CorrespExplorer wurde von Christopher Pollin mit Coding-Agenten in Claude Code unter Anwendung der Promptotyping-Methode entwickelt. Welche Modelle beteiligt waren, nennt die README des Repositorys.

Im November 2026 entstand für die Fertigstellung des Aufsatzes zur Promptotyping-Methode eine weitere Iteration mit Claude Code (Claude Opus 5.5 und Claude Fable 5.2). Seither liest das Werkzeug auch TEI, das jeden Brief in einem eigenen Datensatz beschreibt, lädt eine Edition aus vielen Dateien als einen Bestand und zeigt Poststempel, Anschriften, erschlossene Angaben und mehrfach verzeichnete Briefe als das, was sie sind. Anlass waren die Briefmetadaten von Stefan Zweig Digital, die das Werkzeug nicht ausliefert.

Lizenz und Kontakt

CorrespExplorer ist Open-Source-Software. Der Code steht unter der MIT-Lizenz, Dokumentation und Wissensbasis unter CC BY 4.0. Gebündelte Forschungsdaten behalten die Lizenz ihrer Herausgeber.

Der Beispieldatensatz ist der CMIF-Export des Hugo Schuchardt Archivs, herausgegeben vom Zentrum für Informationsmodellierung der Universität Graz unter CC BY 4.0. Für den Explorer ist er als JSON aufbereitet, nach Personen, Orten, Themen und Sprachen indexiert und um Koordinaten aus Wikidata ergänzt.

Ein Projekt von DHCraft. Rückmeldungen nimmt das Repository auf GitHub unter Issues entgegen.
