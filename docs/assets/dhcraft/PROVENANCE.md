# assets/dhcraft

Shared header and footer files of the DHCraft project sites, copied unchanged on 2026-11-14 from the repository `DigitalHumanitiesCraft/brand-assets`, folder `web/`, at commit `b0641cc`: `dhcraft-tokens.css`, `dhcraft-components.css`, `dhcraft-mark-watercolor-128.png`, `LICENSE.md` and the four WOFF2 fonts with their OFL texts under `fonts/`.
